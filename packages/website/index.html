Die App — läuft komplett in deinem Browser

KI-Rechenzeit, verschlüsselter Chat, Wallet mit Swaps zwischen Lightning und Solana, und deine Einnahmen als Provider. Kein Download nötig.

Identität = Nostr-Key (nsec), lokal in deinem Browser. Zahlungen = Lightning (sats). Compute = Provider-Knoten im Netz, nicht wir.

Wie es funktioniert

Verschlüsselter Chat

Nachrichten laufen über mehrere Relays. Ein Relay kann Nachrichten zurückhalten, aber nicht fälschen.

KI-Marktplatz (NIP-90)

Stell eine Frage, Provider im Netz antworten. Bezahlt wird pro Anfrage in Sats.

Wallet und Swaps

Lightning und Solana. Swaps laufen direkt über Hashlocks — ohne Bridge und ohne Verwahrer.

Sybil-Schutz ohne Zentrale

Arbeitsnachweis und Vertrauensnetz machen falsche Konten teuer. Den Ruf eines Providers bildet deine App aus eigenen Quittungen und denen deiner Kontakte – nicht aus Selbstauskünften.

Kein Token, kein Mixer

Läuft mit BTC und SOL. Jede KI-Zahlung ist fest aufgeteilt: 94 % Provider, 2 % Entwicklung, 1,5 % Relays, je 0,5 % für die Werber beider Seiten, 1 % Hosting, 0,5 % bleiben bei dir als Prüfbudget – direkt an die Empfänger, ohne Topf.

Ohne Betreiber

Das Swap-Programm wird nach einer Testphase unveränderlich gemacht. Der Code ist offen; weitere Bezugsquellen der App sind vorbereitet.

Rechenzeit vermieten — drei Einnahmen, ein Knoten

Ein GPU-Gerät (Gaming-PC, Mac Mini, NVIDIA DGX Spark, VPS) wird zum Provider-Knoten. Du verdienst mit KI-Aufträgen (94 % jeder Zahlung), mit Swap-Liquidität (LP-Gebühr, braucht LND) und – wenn du willst – mit bezahltem Zugang zu deinem Relay (Sats oder SOL).

Linux (ein Befehl)

Ein Befehl richtet Ollama, ein Modell, den Dienst und deine Lightning-Adresse ein (Prüfsumme daneben: install.sh.sha256). Die App zeigt ihn unter Verdienen › Hosten.

bash <(curl -fsSL https://3dagi.github.io/freedom-app/install.sh)

Headless (Server)

Überall wo Node läuft:

git clone https://github.com/3DAGI/freedom-app
cd freedom-app && npm ci
cd packages/node
NODE_LUD16=provider@knoten.example.org npm start

Beim ersten Start erzeugt der Knoten einen Schlüssel und zeigt ihn als NODE_SECRET_KEY an – sichern und beim nächsten Start setzen.

Mit LP-Modus

Zusätzlich Swap-Liquidität anbieten (braucht LND und eine eingeschränkte Macaroon – mit der vollen Admin-Macaroon startet der Knoten nicht):

lncli bakemacaroon --save_to=freedom-lp.macaroon \
  info:read invoices:read invoices:write \
  offchain:read offchain:write
LP_ENABLED=1 LND_MACAROON=freedom-lp.macaroon \
npm start

Dein Knoten veröffentlicht signierte Leistungs-Events – öffentlich prüfbar. Der Verdienen-Tab der App zeigt sie, wenn App und Knoten denselben Schlüssel nutzen. Kein Konto, kein Dashboard-Server — die Relays sind die Quelle.

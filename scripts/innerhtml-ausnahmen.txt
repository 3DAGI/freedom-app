#
# Format: datei|ausdruck|Begruendung. Jede Zeile deckt genau EINE Fundstelle
# ab; derselbe Ausdruck an einer weiteren Stelle braucht eine eigene Zeile.
# '|' im Ausdruck steht als '¦'. Hier stehen nur Werte, die nachweislich
# sicher sind: eigene Konstanten, lokal gezaehlte Zahlen, Math.*, schon beim
# Zusammenbau maskierte Teile. Fremddaten (Relays, Provider, Profile, Raeume,
# Dateinamen, URLs) gehoeren NICHT hierher, sondern in escapeHtml()/ganzeZahl().

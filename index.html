freedom — agent

Die App — läuft komplett in deinem Browser

KI-Marktplatz (pay per job in sats), unzensierbarer Chat, non-custodial Wallet mit Atomic Swaps (Lightning ↔ Solana), deine Provider-Einnahmen. Kein Download nötig — aber installierbar als PWA (Seeker/iOS/Desktop) für Offline-Start.

Identität = Nostr-Key (nsec), lokal in deinem Browser. Zahlungen = Lightning (sats). Compute = Provider-Knoten im Netz, nicht wir.

Wie es funktioniert

Unzensierbarer Chat

Multi-Relay Nostr (Outbox-Modell). Ein Relay kann Nachrichten nur vorenthalten, nie fälschen — Redundanz neutralisiert Zensur.

KI-Marktplatz (NIP-90)

Stelle eine Frage, Provider im Netz antworten. Bezahlt wird pro Job in sats — mit Streaming-Sats (Session-Protokoll) ohne Transaktion pro Nachricht.

Non-custodial Wallet + Swaps

Lightning (sats) + Solana. Atomic Swaps (HTLC) tauschen native Assets — keine Bridge, kein Custodian, kein Topf zum Hacken.

Sybil-Schutz ohne Zentrale

Proof-of-Work + Web-of-Trust machen Fake-Accounts teuer und wertlos. Reputation ist öffentlich prüfbar (signierte Events).

Kein Token, kein Mixer

Läuft mit BTC/SOL. Die 5%-Protokollfee ist hardcoded (2,5% Development / 2% Provider-Rewards / 0,5% Referral) — im Code fix, nicht änderbar nach Launch.

Betreiberlos & immutable

Contracts keyless (kein Upgrade-Authority), Code P2P gehostet. Das System überlebt jeden Einzelnen — inklusive der Gründer.

Compute vermieten — drei Einnahmequellen, ein Knoten

Ein GPU-Gerät (Gaming-PC, Mac Mini, NVIDIA DGX Spark, VPS) wird zum Provider-Knoten. Du verdienst: KI-Jobs (DVM), Swap-Liquidität (LP-Fees), und das Netz wächst mit jedem Knoten.

Desktop (1-Klick)

freedom launcher für Windows/Mac/Linux. Installiert Ollama, generiert Keys, fragt deine Lightning-Adresse ab — "Verdienen starten".

Headless (Server)

Überall wo Node läuft:

git clone <repo>
cd freedomstack/packages/node
npm install
NODE_LUD16=you@wallet.cash npm start

Mit LP-Modus

Zusätzlich Swap-Liquidität anbieten (braucht LND):

LP_ENABLED=1 \
LND_MACAROON=~/.lnd/…/admin.macaroon \
npm start

Verdienen-Tab in der App zeigt deine Einnahmen (signierte Leistungs-Events, öffentlich prüfbar). Kein Konto, kein Dashboard-Server — die Relays sind die Quelle.

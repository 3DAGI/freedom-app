freedom — agent

Die App — läuft komplett in deinem Browser

KI-Rechenzeit, verschlüsselter Chat, Wallet mit Swaps zwischen Lightning und Solana, und deine Einnahmen als Provider. Kein Download nötig.

Identität = Nostr-Key (nsec), lokal in deinem Browser. Zahlungen = Lightning (sats). Compute = Provider-Knoten im Netz, nicht wir.

Wie es funktioniert

Verschlüsselter Chat

Nachrichten laufen über mehrere Relays. Ein Relay kann Nachrichten zurückhalten, aber nicht fälschen.

KI-Marktplatz (NIP-90)

Stell eine Frage, Provider im Netz antworten. Bezahlt wird pro Anfrage in Sats.

Wallet und Swaps

Lightning und Solana. Swaps laufen direkt über Hashlocks — ohne Bridge und ohne Verwahrer.

Sybil-Schutz ohne Zentrale

Arbeitsnachweis und Vertrauensnetz machen falsche Konten teuer. Reputation ist öffentlich nachprüfbar.

Kein Token, kein Mixer

Läuft mit BTC und SOL. Das Protokoll nimmt 2,5 %: 2,0 % für den Reward-Pool, 0,5 % für Werber. Die App nimmt zusätzlich 2,5 %, abschaltbar.

Ohne Betreiber

Das Swap-Programm wird nach einer Testphase unveränderlich gemacht. Der Code ist offen und liegt an mehreren Orten.

Rechenzeit vermieten — drei Einnahmen, ein Knoten

Ein GPU-Gerät (Gaming-PC, Mac Mini, NVIDIA DGX Spark, VPS) wird zum Provider-Knoten. Du verdienst: KI-Jobs (DVM), Swap-Liquidität (LP-Fees), und das Netz wächst mit jedem Knoten.

Desktop (1-Klick)

freedom launcher für Windows/Mac/Linux. Installiert Ollama, generiert Keys, fragt deine Lightning-Adresse ab — "Verdienen starten".

Headless (Server)

Überall wo Node läuft:

git clone <repo>
cd freedomstack/packages/node
npm install
NODE_LUD16=you@wallet.cash npm start

Mit LP-Modus

Zusätzlich Swap-Liquidität anbieten (braucht LND):

LP_ENABLED=1 \
LND_MACAROON=~/.lnd/…/admin.macaroon \
npm start

Verdienen-Tab in der App zeigt deine Einnahmen (signierte Leistungs-Events, öffentlich prüfbar). Kein Konto, kein Dashboard-Server — die Relays sind die Quelle.
